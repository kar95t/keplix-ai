# 🛰️ Keplix Web Replayer

A lightweight, static Next.js + React Flow trace visualizer designed to replay and inspect multi-agent orbits executed by **Keplix**.

## ✨ Features

- **🪐 React Flow Orbit Graph:** Visualizes the dynamic supervisor state machine, task fan-outs, and parallel worker topologies.
- **⏱️ Step-by-Step Scrubbing:** Scrub through execution timelines and inspect live agent actions, subtasks, and token latencies.
- **📊 Contract Blackboard Inspector:** Inspect active Pydantic contracts, subgraph write-locks, and Git rollbacks in real time.
- **⚡ Static Export Ready:** Exports to static HTML/CSS/JS (`next build`), ready for free zero-config deployment to [Vercel](https://vercel.com) or GitHub Pages.

## 🚀 Quickstart

```bash
cd web_replayer
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the replayer.

## 📂 Loading Traces

Click **"Load trace.json"** in the top navigation bar to drop in any `trace.json` or `graph.json` generated by a `keplix run` execution!
